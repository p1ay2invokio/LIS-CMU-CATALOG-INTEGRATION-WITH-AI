Place your cloudflared tunnel credentials file (<Tunnel-UUID>.json) in this folder.
On Mac/Linux, you can find it in: ~/.cloudflared/<Tunnel-UUID>.json
On Windows, you can find it in: C:\Users\<username>\.cloudflared\<Tunnel-UUID>.json

If you run ./build-setup.sh on a Mac that already has ~/.cloudflared/*.json,
it will copy the .json file here automatically.
